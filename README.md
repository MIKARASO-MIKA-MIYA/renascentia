# RENASCENTIA

RENASCENTIA — русскоязычный студенческий исследовательский портал о философии, науке, истории и искусстве эпохи Возрождения. Версия **0.0.5** улучшает вставку, сохранение и предпросмотр материалов в редакторе. Главная страница, восемь исследовательских программ и восемь статей с источниками доступны на прежних адресах. Визуальные ориентиры — редакционная структура официального сайта NASA и макеты проекта. [Сайт NASA](https://www.nasa.gov/)

## Запуск и проверки

Требуются Node.js 24.x и npm.

```bash
npm ci
npm run dev
```

`npm run dev` запускает портал по адресу `http://localhost:3000`.

```bash
npm run typecheck
npm run lint
npm run format:check
npm run test:cms
npm run build
npm start
```

Зависимости закреплены в `package-lock.json`. Проект использует Next.js App Router, TypeScript Strict Mode, Tailwind CSS, Motion, Lucide React, ESLint и Prettier.

## Вход и редактор содержимого

При первом открытии главной страницы можно войти как гость или перейти к входу владельца и редактора. Режим гостя сохраняется в браузере без регистрации. Прямые ссылки на исследования и другие публичные страницы открываются сразу.

Войти можно через значок аккаунта в шапке или по адресу `/admin/login`. После входа Supabase определяет существующую роль, и сайт открывает главную страницу. В меню аккаунта доступны профиль `/profile`, переключатель карандашей, просмотр сайта, админка и выход. Просмотр сайта скрывает карандаши и сохраняет сессию. Панель `/admin` включает каталог, черновики, историю версий, медиатеку и инструменты владельца.

- [Подключение Supabase и Vercel](docs/SUPABASE_SETUP.md)
- [Руководство редактора](docs/CMS.md)
- [Схема PostgreSQL](docs/DATABASE.md)
- [Права доступа и проверка контента](docs/SECURITY.md)

Редактор принимает повторяющиеся заголовки и пустые абзацы. При сохранении он автоматически исправляет безопасные стили вставленного текста и генерирует уникальные якоря. Если сохранить материал не удалось, редактор показывает причину, сохраняет правки на экране и позволяет скачать их как черновик. Предпросмотр сохранённого черновика открывает фактический макет страницы.

У пользователей с правом публикации правки автоматически появляются на сайте через короткую паузу в редактировании. У редакторов без такого права автоматически сохраняется черновик. Кнопка «Сохранить черновик» оставляет текущие правки в черновике. После снятия материала с публикации открытый редактор сохраняет последующие правки в черновике до ручной публикации или закрытия редактора.

Для материалов, превышающих прежний лимит базы, примените [миграцию 0.0.5](supabase/migrations/20261125000200_cms_document_size.sql). Длина текста, число абзацев и число блоков не ограничены отдельными счётчиками. Один запрос на сохранение по-прежнему должен помещаться в серверный лимит около 4 МБ.

Для проверки исходных данных без подключения к Supabase используйте `npm run cms:seed -- --check`. Для сквозного теста запустите `npm run test:browser`. Тест использует локальный PostgreSQL (PGlite) и тестовый HTTP-сервис. На Windows он использует Edge при наличии. На другой системе выполните `npx playwright install chromium` или задайте `CMS_BROWSER_BIN` с путём к браузеру.

## Компоненты и данные

- `src/app` — маршруты, макет, метаданные, дизайн-токены в `globals.css` и стили главной и навигации.
- `src/components` — `SiteHeader`, `HeaderNavigation`, `ExploreMegaMenu`, `NavigationDropdown`, `SearchBar`, `PublicationCard`, `ImageViewer`, `SiteFooter` и общие компоненты страниц.
- `src/components/home` — `AnnouncementBar`, `HeroCarousel`, `FeaturedResearch`, `FeaturedVideo`, `ResearchPrograms`, `ResearchProgramCard`, `ArtworkOfTheDay`, `ImageGallery`, `ArchiveBanner`, `TopicGrid`.
- `src/content` — локальные TypeScript-данные программ, публикаций, визуальных источников, тематических подборок и видео.
- `src/lib` — поиск, чтение локальных записей, расчёт времени чтения и метаданные.

Меню поддерживает Tab, Enter, стрелку вниз, Escape и закрытие по нажатию за пределами панели. В галерее доступны клавиши со стрелками, Escape и просмотр на весь экран. Карусель поддерживает ручное переключение, паузу и системную настройку уменьшения движения.

Программы хранятся в `src/content/programs.ts`, статьи — в `src/content/articles.ts`. Ссылки статей на программы проверяются типами. Время чтения рассчитывается по числу слов в тексте из расчёта 180 слов в минуту с округлением вверх. Для новых записей укажите уникальный `slug`, заголовок, краткое описание и статус. К опубликованной статье добавьте текст, проверенные источники и ключ изображения.

## Изображения и лицензии

В `public/images` находятся 16 локальных WebP. Авторство, ссылки на оригиналы, лицензии, размеры и альтернативные описания перечислены в [реестре изображений](src/content/images.ts) и на странице `/sources#images`. Перечень включает панораму Флоренции Дллу, фотографию Понте-Веккьо Эрика Килби, изображения из Капитолийских музеев, Музея Галилея, Королевской библиотеки Турина и Библиотеки Конгресса США. Файлы получены по карточкам Wikimedia Commons и адаптированы по размеру. «Афинская школа» показана фрагментом с Платоном и Аристотелем. [Wikimedia Commons](https://commons.wikimedia.org/) · [Описание фрески в Музеях Ватикана](https://www.museivaticani.va/content/museivaticani/en/collezioni/musei/stanze-di-raffaello/stanza-della-segnatura/scuola-di-atene.html)

Изображения выводятся через `next/image` с адаптивным `sizes`. Первый баннер загружается с приоритетом, остальные изображения — отложенно. Manrope поставляется локально в WOFF2.

## Vercel и SEO

Проект использует пресет Next.js и Node.js 24.x. Для установки и сборки предусмотрены `npm ci` и `npm run build`. Для канонических адресов укажите публичный домен в `SITE_URL` или предоставьте системную переменную `VERCEL_PROJECT_PRODUCTION_URL`. При локальном запуске без домена карта сайта остаётся пустой. Страницы поиска и записи в подготовке помечены `noindex`. [Node.js на Vercel](https://vercel.com/docs/functions/runtimes/node-js/node-js-versions) · [Переменные Vercel](https://vercel.com/docs/environment-variables/system-environment-variables)

Подтверждены отсутствие горизонтальной прокрутки, переходы по программам и поиск, открытие и закрытие мегаменю, переключение и пауза карусели, загрузка изображений и полноэкранный просмотр. На скриншотах проверены главная, мегаменю, мобильные карточки и превью «Афинской школы».
