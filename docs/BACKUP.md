# Резервное копирование

Владелец может скачать копию JSON через «Настройки» или выгрузить один материал из списка. Для статей также доступен Markdown. В нём сохраняются заголовки, списки, базовые стили, ссылки, таблицы и ссылки на медиа. JSON сохраняет редакторские поля и блоки полностью.

1. Скачайте JSON и храните его в закрытом хранилище. Экспорт содержит последнее состояние каждого материала, в том числе черновики.
2. Для восстановления откройте «Настройки», выберите JSON и подтвердите операцию. Один файл импорта должен помещаться в серверный лимит запроса около 4 МБ. Объёмные проекты можно переносить отдельными JSON-файлами из списка материалов.
3. Импорт создаёт новые версии черновиков транзакционно. Проверьте результат и опубликуйте нужные записи. При параллельной правке импорт прекращается с сообщением о конфликте.

JSON содержит ссылки на медиа, но не файлы, аккаунты или полную историю. Сохраняйте отдельно PostgreSQL и объекты приватного бакета `cms-images` вместе с их путями и записями `media_assets`. При восстановлении в другом проекте привязки медиа должны указывать на восстановленные идентификаторы. Проверяйте сохранность резервных копий восстановлением на отдельном проекте.
